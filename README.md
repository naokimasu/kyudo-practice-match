# 弓道 練習試合アプリ

## 概要

練習試合に近い形式で練習できるようにするためのWebアプリです。

仮想の対戦相手の的中結果を生成することで、
いつでも試合形式を意識した練習ができるようにしました。

## 制作背景

弓道の練習では、自分たちの的中結果だけを見ながら練習することが多く、
実際の試合のように「相手の結果を意識しながら引く」という状況を作ることが難しいと感じていました。

そこで、仮想の対戦相手を作り、
練習試合を再現できるWebアプリを制作しました。

## 主な機能

- 仮想の対戦相手を設定
- 対戦相手の的中結果をランダム生成
- 人数に応じた試合形式の変更
- 的中数の範囲指定
- 試合形式を意識した結果表示
- 表示タイミングの設定

## 工夫した点

### 1. 実際の弓道の練習を想定した設計

単純にランダムな結果を表示するのではなく、
人数や的中数などを設定できるようにすることで、
さまざまな練習状況を再現できるようにしました。

### 2. Flaskのセッションを利用した状態管理

ユーザーが設定した対戦条件を、
画面遷移後も利用できるようにFlaskのsessionを使用しています。

### 3. JavaScriptを利用した表示制御

対戦相手の結果を一度に表示するだけでなく、
実際の試合を意識したタイミングで表示できるよう、
JavaScriptによる表示制御を実装しました。

### 4. Web上で利用できる状態まで公開

ローカル環境で動作させるだけでなく、
Renderを利用してデプロイし、
ブラウザから利用できる状態まで構築しました。
